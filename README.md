# FormatDesk · Лендинг «Алхимия ясности»

Статический лендинг B2B-сервиса FormatDesk (экран версии форматного приказа ФНС: реквизиты с якорями XSD и каркас для макета). Пересобран 24.11.2026 точно по макету Figma (файл `ФНС`, узел 92:2, 1440×5460): шрифты Cormorant Garamond + Inter, цветная гравюрная графика (duo, riders 01–04, росток из колбы, драконы-медальон) выгружена из Figma рендерами с запечёнными фильтрами.

## Структура

- `index.html`, `styles.css`, `script.js` — лендинг, сборка не требуется.
- `assets/eng-*.png`, `assets/hero-garden.jpg` — гравюры и фон арки из Figma.
- `assets/01-catalog.png` … `assets/04-mockup.png` — скриншоты Lo-Fi прототипа (сняты 17.11.2026), показаны в витрине раздела «Как это работает: четыре шага»; шаги кликабельны и переключают экран и подпись.
- `prototip/index.html` — однофайловый Lo-Fi прототип, цель всех CTA («Открыть прототип», «Открыть Lo-Fi прототип»).

## Запуск

```bash
python3 -m http.server 8950
# → http://localhost:8950/
```

Или просто открыть `index.html` в браузере.

## Макет

Ширина контента 1296 px при полях 72 px, секции: Навигация → Первый экран → 01 Для кого → 02 Проблема (тёмная) → 03 Экраны → 04 Состав продукта (MVP) → Приглашение → Подвал. Страница десктопная: при ширине окна меньше 1180 px включается горизонтальный скролл.
