Дизайн-система продукта

FormatDesk

Сервис для команды оператора ЭДО: следит за форматными приказами ФНС и собирает «экран версии» — реквизиты приказа, группы полей и макет документа с якорями на официальные XSD. Дизайн-система задаёт общий визуальный язык лендинга и сервиса, чтобы переход «сайт → продукт» не требовал от пользователя нового привыкания.

Аудитория

S1 · Дизайнер карточки ЭПД. Собирает макет регламентированного документа. Нужен состав полей по титулам без созвона с аналитиком.

S2 · Системный аналитик. Переносит приказ и XSD в постановку. Нужны действующая версия, реквизиты и якоря на источник для сверки.

По материалам корпуса: PRD.md, проблемные интервью R1–R4 (волна 21.10.2026).

Принципы

Доверие через источник

Любое значение можно проверить: рядом якорь на XSD и приказ. Ничто не выглядит «придуманным».

Спокойная плотность

Данных много — шума мало. Таблицы и деревья читаются построчно, без лишних рамок и теней.

Один акцент

На экране одно главное действие. Глубокий зелёный — действие, терракота — ссылки на источники и редкие метки.

Документ как бумага

Макет документа — белый «лист» на тёплом креме. Заголовки — книжный сериф, данные — ровный гротеск.

Доступность по умолчанию

Контраст текста ≥ 4.5, видимый фокус, управление с клавиатуры, уважение к prefers-reduced-motion.

Честные состояния

Загрузка, пусто, ошибка — всегда с объяснением и следующим шагом. Ошибка никогда не винит пользователя.

Визуальное направление

«Тёплый архив»: кремовая бумага, глубокий зелёный, терракота и песочные границы. Книжный сериф Cormorant Garamond для заголовков — как на лендинге; Inter для данных; Space Mono для кодов и XPath. Палитра собрана из согласованных референсов бренда (карта «референс → токен» — в разделе «Основы» и в README).

Основы

Токены и базовые правила

Все значения хранятся в одном источнике — tokens.css (CSS-переменные) и tokens.json (машинно-читаемая копия). Компоненты и экраны продукта используют только переменные, без «голых» значений. Тема одна — светлая: продукт работает с документами при дневном свете офиса; тёмная тема в объём р1 не входит.

Логотип

Знак — «Оракул»: полумесяц и смотрящий глаз с лучами над свитком с печатью-искрой. Гравюрная манера лендинга: штриховка пером, неровные края, форматы и немного магии. Словесная марка — Cormorant Garamond Bold, «Desk» — терракотой, как на лендинге.

Охранное поле — высота глаза знака с каждой стороны. Минимальная высота знака — 16px, полного логотипа — 24px.

Размерный ряд (шаблон из Figma): микро 16–32px — упрощённый силуэт: глаз, три луча, свиток; компакт 48–96px — без мелкой штриховки; полный 128px и больше — вся гравюра. Чем меньше размер, тем проще знак; словесная марка неизменна.

На тёмном (глубокий зелёный) — инверсная версия: знак и «Format» белые, «Desk» — янтарной.

Нельзя: менять пропорции и цвета, поворачивать, ставить на пёстрый фон без подложки. Файлы: assets/logo-lockup.webp, assets/logo-lockup-inv.webp, assets/logo-znak.webp, assets/logo-znak-inv.webp, assets/favicon.png. Растровые мастера PNG (полный / компакт / микро, размерный ряд 16–256px) — в папке проекта.
